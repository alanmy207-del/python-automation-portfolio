# Python Automation & Scripting Portfolio

A collection of production-ready Python scripts demonstrating automated web scraping, target monitoring, and filesystem utilities.

## Included Modules

1. **Web Scraper (`scraper.py`)**
   - Automatically extracts structured content from target HTML endpoints.
   - Parses elements using `BeautifulSoup` and exports organized records to clean `.csv` files.

2. **System & Web Monitor (`monitor.py`)**
   - Periodically checks target server HTTP statuses and uptime metrics.
   - Generates structured JSON status payloads for logging and alerting.

3. **Directory Organizer (`organizer.py`)**
   - Automated filesystem cleanup script.
   - Categorizes and sorts raw file downloads into organized subdirectories by file type.
